## 🌟 Highlights

- **Dynamic Theme Switcher**: Full support for Dark & Light modes with persistent `localStorage` preference and anti-flicker loader.
- **Interactive Project Showcase**: Detailed modals with architecture overviews, problems & solutions, and live preview links.
- **Integrated Resume Viewer**: In-browser formatted resume modal with print-to-PDF and text download features.
- **Filterable Skills Matrix**: Categorized competencies across Programming (Java, Python), Web Development, Core CS (OOP, DSA), Workflow Automation (n8n, Webhooks, REST APIs), and Tools.
- **Interactive Contact Panel**: 1-click email copy to clipboard with toast confirmation and direct mail generator.

## 💻 Local Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Rizwan786r/portfolio.git
   cd portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
